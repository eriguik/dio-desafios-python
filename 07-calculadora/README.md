# 07 - Calculadora (POO)

## 📋 Descrição

Implementa a classe `Calculadora` aplicando os princípios da Programação Orientada a Objetos (POO). A classe possui um método para realizar a soma entre dois números inteiros, encapsulando a lógica matemática da adição.

📚 Documentação oficial usada como referência: [Classes em Python](https://docs.python.org/pt-br/3/tutorial/classes.html)

## ⬇️ Entrada

Dois números inteiros, um por linha.

## ⬆️ Saída

O resultado da soma dos dois números.

## 🧪 Exemplos

| Entrada | Saída |
|---------|-------|
| 5<br>5  | 10    |
| 8<br>8  | 16    |
| 20<br>10 | 30   |
