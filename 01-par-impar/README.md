# 01 - Par ou Ímpar

## 📋 Descrição

O programa recebe um número inteiro como entrada e determina se ele é **par** ou **ímpar**, retornando uma string indicando `Par` ou `Ímpar`.

📚 Documentação oficial usada como referência: [Controle de Fluxo em Python](https://docs.python.org/pt-br/3/tutorial/controlflow.html)

## ⬇️ Entrada

Um único número inteiro.

## ⬆️ Saída

Uma string: `Par` ou `Ímpar`.

## 🧪 Exemplos

| Entrada | Saída  |
|---------|--------|
| 2       | Par    |
| 5       | Ímpar  |
| 6       | Par    |

## ▶️ Como executar

```bash
python main.py
```
