# 04 - Soma de Tupla

## 📋 Descrição

Função que recebe uma tupla de números inteiros e retorna a soma de todos os elementos. Deve funcionar para tuplas de qualquer tamanho.

📚 Documentação oficial usada como referência: [Tuplas em Python](https://docs.python.org/pt-br/3/library/stdtypes.html#tuple)

## ⬇️ Entrada

Uma única linha de texto com vários números inteiros separados por espaços.

## ⬆️ Saída

A soma de todos os números, no formato: `A soma dos elementos da tupla é: <soma>`

## 🧪 Exemplos

| Entrada       | Saída                                       |
|---------------|----------------------------------------------|
| 2 5 6 7 9     | A soma dos elementos da tupla é: 29          |
| 9 8 7 6 5     | A soma dos elementos da tupla é: 35          |
| 50 50 50 50   | A soma dos elementos da tupla é: 200         |

## ▶️ Como executar

```bash
python main.py
```
