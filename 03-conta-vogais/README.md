# 03 - Conta Vogais

## 📋 Descrição

Conta quantas vogais (sem acentuação: `a, e, i, o, u`) existem em uma string, ignorando maiúsculas/minúsculas. Caracteres acentuados (`ã`, `ç`, `é`, etc.) não são contados.

📚 Documentação oficial usada como referência: [For Statements](https://docs.python.org/pt-br/3/tutorial/controlflow.html#for-statements)

## ⬇️ Entrada

Uma única string contendo letras/palavras.

## ⬆️ Saída

Um número inteiro com o total de vogais encontradas.

## 🧪 Exemplos

| Entrada      | Saída                                          |
|--------------|-------------------------------------------------|
| Python       | O número de vogais na string 'Python' é: 1       |
| Programação  | O número de vogais na string 'Programação' é: 4  |
| Função       | O número de vogais na string 'Função' é: 2       |
