# 08 - Classe Pessoa (POO)

## 📋 Descrição

Classe `Pessoa` com os atributos `nome` e `idade`, e um método que retorna uma representação formatada dos dados. O objetivo é praticar a criação e manipulação de objetos em POO, usando atributos e métodos para encapsular dados e comportamentos.

📚 Documentação oficial usada como referência:
- [Classes em Python](https://docs.python.org/pt-br/3/tutorial/classes.html)
- [Métodos](https://docs.python.org/pt-br/3/library/stdtypes.html#methods)

## ⬇️ Entrada

- Nome da pessoa (string)
- Idade da pessoa (inteiro)

Um valor por linha.

## ⬆️ Saída

Uma string formatada: `Nome: {nome}, Idade: {idade}`

## 🧪 Exemplos

| Entrada                | Saída                          |
|------------------------|---------------------------------|
| Mary Silva<br>32       | Nome: Mary Silva, Idade: 32     |
| John Soares<br>20      | Nome: John Soares, Idade: 20    |
| Marcelly Reis<br>40    | Nome: Marcelly Reis, Idade: 40  |
