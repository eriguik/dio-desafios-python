# DIO Desafios Python

Repositório com a resolução dos desafios de código da trilha Python da [DIO](https://www.dio.me/).

Cada desafio fica isolado em sua própria pasta, com solução e testes unitários (`pytest`).

|---|---------|-------|
| 01 | Par ou Ímpar | [`01-par-impar/`](./01-par-impar) |
| 02 | Ano Bissexto | [`02-ano-bissexto/`](./02-ano-bissexto) |
| 03 | Conta Vogais | [`03-conta-vogais/`](./03-conta-vogais) |
| 04 | Soma de Tupla | [`04-soma-tupla/`](./04-soma-tupla) |

## ▶️ Como rodar um desafio

```bash
cd NN-nome-do-desafio
python main.py
```

## ✅ Como rodar os testes de um desafio

```bash
cd NN-nome-do-desafio
pip install pytest
pytest
```
